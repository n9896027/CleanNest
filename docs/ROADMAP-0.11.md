# CleanNest 0.11.0 路线图：可信分发与真实稳定性

状态：开发中。目标版本为 0.11.0（Build 49），不代表已经提交、打 tag、创建 GitHub Release 或通过全部发布门。

## 版本目标

CleanNest 已具备清理、卸载、磁盘、Agent 工作区、本地模型、系统监控、维护、只读 MCP 与本机学习等完整能力。0.11.0 不以扩大删除范围或增加大量新功能为目标，而是让源码、安装包、真实稳定性和用户说明互相对上。Build 49 进一步彻底移除了外部 Mole 引擎及其安装、更新和路径配置入口，系统状态改由内置原生监测、内存、电源与进程采样提供。

本版本必须保持以下边界：

- 扫描缺口、权限不足和模型不确定只能降低结论，不能扩大执行权限。
- AI 仍只提供建议；MCP 仍为 stdio only、只读、无网络监听。
- 不自动清理整个 Library、Containers、云盘或用户文档。
- 不扩大 Agent 私有会话、索引、记忆、凭据、运行时和虚拟机的处置权限。
- 不引入公网 AI、自动下载大模型或自动替换 App。
- 不自动安装 Homebrew 或任何外部清理引擎；Homebrew 仅作为普通开发缓存的扫描对象。

## 当前基线与证据边界

- 0.10.1（45）本机 PKG 已完成 Universal 2 四组件构建、Developer ID Application / Installer 签名、Apple 公证、票据装订和 Gatekeeper 评估。
- 0.11.0（49）候选已实测 238 项测试、0 失败、1 跳过；CleanNestSelfTest、严格本地化、Universal 2 构建、签名、公证、装订、Gatekeeper 和 PKG 独立解包复核均通过。
- Build 49 已删除外部引擎定位、JSON 解码、安装状态与设置入口；原生替代没有可靠证据的健康分、缓存和交换空间等字段保持空值，不生成猜测数据。虚拟机中的 Build 48 → 49 升级验收仍在执行。
- Build 48 已在 macOS 27.2.1 Apple Silicon 虚拟机完成 Build 47 → 48 升级、清理扫描／取消／重扫、MCP 原样合批请求和登录项注册；这不是 Build 49 的证据，也不是干净首次安装。
- Build 46 的无效 XPC peer requirement 崩溃与 Build 47 的 MCP 合批输入丢行均已修复并复验；详细证据见 `docs/VERIFICATION-0.11.0.md`。
- 上述结果不等于 Intel 真机、最低 macOS 版本、宿主机旧版升级、完整核心流程、三语言人工验收或真实 48 小时已通过。
- 严格源码本地化自动门已清零直接 UI 与动态插值缺口；Catalog 2506 条三语言非空值及格式占位符检查通过，人工界面门仍未执行。
- 0.9.0～0.11.0 的现有改动必须在正式发布前形成经过审查的干净提交；本路线图不授权自动提交、推送、打 tag 或发布。

## 执行顺序

1. **基线**：版本、脚本、文档和可审查源码先对齐。
2. **修复**：状态回归与本地化并行；发现阻断缺陷先修复再生成 RC。
3. **实测**：优先生成正式 Universal 2 PKG，完成干净环境安装、核心流程和本机升级数据保留；真实耐久只作可选稳定性观察。
4. **冻结**：只接受阻断级修复；最终包必须从同一通过检查的提交重建并重新验证。

## 明确暂缓
