## 问题诊断

原页面用官僚词汇描述一个其实简单的功能："提案/审核/启用/规则簇/证据次数"。用户无法从文案回答三个关键问题：这是什么、启用后会发生什么、会不会替我删文件。

功能本身的真实行为（文案改写的依据）：

1. 清理页对某项点"以后优先清理/优先保留" → 生成一条待确认习惯；
2. 习惯在本页汇总成簇（类型+位置+风险+新旧）；
3. 点"启用"后，下次扫描的清理列表里，同类文件自动排前（优先复核）或排后（优先保留）；
4. 全程只影响排序：不自动勾选、不删文件、不碰进程。
