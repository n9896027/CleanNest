# CleanNest 0.7.2 本机验证报告

日期：2026-08-27
版本：0.7.2（Build 29）
环境：Apple Silicon（arm64）、macOS 26.5.2（25F84）、Xcode 26.6、本地稳定代码签名身份
分支：`agent/0.7-series`
基线提交：`1fc1a28`（0.7.1 本机里程碑）

## 结论

0.7.2 的本机里程碑验收通过。清理页已经从候选列表升级为有证据的工作台：能说明扫了哪些位置、看了多少文件、跳过了什么、候选属于什么类别，并在底部用处理篮统一展示选择、恢复和执行前重验。

真实辅助功能树操作验证了截图全选、重复组保留副本、最终复核和活动详情；全程使用合成候选，没有扫描或移动用户个人文件。磁盘浏览的真实 App 入口已经从主目录改为启动卷 `/`，显示当前卷名 Macintosh HD，但进入页面不会自动开始全盘扫描。

这是本地源码与 App 构建验证，不是 GitHub 正式 Release。本报告没有证明 Intel 真机、48 小时耐久、Developer ID 签名、Apple 公证或真实个人文件批量处置。

## 尚未证明

- 清理工作台交互使用合成候选；单元测试使用临时目录。没有拿用户真实截图、下载文件或重复文件执行批量废纸篓操作。
- 全页巡游使用合成数据；真实 Agent 扫描另有独立场景。超大下载/媒体树、云盘占位和多卷重复文件仍需后续专项真机耐久回归。
- APFS 即时变化会受系统并发活动影响，只有在用户清空废纸篓后才能谈最终释放空间；0.7.2 没有把理论容量冒充为已释放。
- 未完成 48 小时常驻、多轮睡眠/唤醒、Intel 真机或全语言 VoiceOver 回归；这些仍属于 0.7.5/0.7.9。
- `Yuan OS Local Code Signing` 只保持本机 TCC 身份，不是 Developer ID；没有公证、staple、Gatekeeper 分发验证或普通用户安装包。
- 本轮未推送、创建 PR、合并、打 tag 或发布 GitHub Release；远端状态没有被本报告冒充为通过。
