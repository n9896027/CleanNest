# CleanNest 0.7.1 本机验证报告

日期：2026-08-27
版本：0.7.1（Build 28）
环境：Apple Silicon（arm64）、macOS 26.5.2（25F84）、Xcode 26.6、本地稳定代码签名身份
分支：`agent/0.7-series`
基线提交：`110c177`（0.7.0 本机里程碑）

## 结论

0.7.1 的本机里程碑验收通过。总览已改为 1–3 项任务队列，每项明确来源、最后验证、影响、当前原因和下一步；设置拆为七个可直达分栏；活动记录支持搜索与类型、结果、时间筛选，累计成果与可清空明细独立持久化。

真实辅助功能树点验证明，总览任务和常用入口具有按钮角色、完整语义与可执行 `AXPress`；从总览最近结果可直接进入活动详情。三组内存门禁全部通过，未因新信息架构破坏 0.7.0 的页面生命周期成果。

这是本地源码与 App 构建验证，不是 GitHub 正式 Release。本报告没有证明 Intel 真机、48 小时耐久、Developer ID 签名、Apple 公证或远端 CI 当前状态。

## 0.7.1 验收门

| 验收项 | 本机结果 |
| --- | --- |
| 总览任务队列 | 实际显示 3 项；每项读屏语义包含来源、最后验证、影响、为什么现在与下一步，并具有 `AXPress` |
| 任务直达 | 从总览的“确认受保护目录访问”一次点击即进入“扫描与隐私”，满足不超过两次点击 |
| 设置分层 | 辅助功能树真实显示常规、菜单栏、扫描与隐私、本机 AI、历史与存储、高级、关于七个按钮；点击后只展示对应分栏 |
| 本机 AI 边界 | 设置只保存回环地址、API 短名与自启程序；启停、守护、端口、客户端实连与“OK”最小测速返回本地模型运行中心 |
