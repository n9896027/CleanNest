## 界面验收

使用完全合成、不读取用户活动、学习记录、模型目录或磁盘容量的演示模式检查：

- 总览：版本与 Build、洞察闭环、主任务和下一步均可见。
- 磁盘浏览：常规窗口宽度下为左侧项目、右侧决策证据的主从布局；目录整体处理依然只读。
- 本机学习：仅有合成的 1 条待审核提案和 1 条已启用规则，未混入已有本机记录。
- 系统状态：电池事实、内存中文解释、可退出进程和系统受保护进程均可见。
- 设置：oMLX 请求 ID 为短名 `Qwen3.8-27B-Uncensored-8bit`，并显示健康延迟、首字、完整响应、权重和内存余量提示。
- 活动记录：导出、单独清空和打开废纸篓的边界清晰。
