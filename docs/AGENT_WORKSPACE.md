# Agent 工作区

CleanNest 0.6.2 把 Codex 与 Claude 留在本机的会话、备份、生成资源、缓存、日志、运行时、虚拟机和状态索引整理为一本只读占用账本。它的目标不是把“Agent 生成的东西”全部当垃圾，而是先回答四个问题：

- 哪个 Agent 正在占用空间？
- 空间花在会话、缓存、备份还是运行环境？
- 哪些文件仍被进程打开或近期写入，必须保护？
- 与上次完整基线相比，是否出现超大文件或明显增长？

## 0.6.2 能做什么

- 在独立 XPC 扫描进程中读取元数据，主 App 保持轻量。
- 用打开文件表与近 15 分钟修改时间保护活跃会话。
- 显示分配块口径的实际占用、逻辑大小、文件数、最大文件和安全分类。
- 用上一次完整观测识别增长；基线只保存分类总量，不保存路径。
- 预览 0.6.3 可能归档或移入废纸篓的静置部分。

## 0.6.2 不做什么

- 不读会话正文、工具输出内容、项目代码、提示词或凭据。
- 不自动选择、归档、压缩、移动或删除文件。
- 不关闭 Codex、Claude 或其他 Agent 进程。
- 不把“预览体积”宣称为最终 APFS 可释放空间。
- 不猜测尚未验证的 Agent 目录；0.6.4 会按证据逐个增加适配器。
