日期：2026-08-26
版本：0.6.2（Build 23）
环境：当前 Apple Silicon Mac、macOS、本地稳定代码签名身份

## 结论

0.6.2 P0 已完成 Codex 与 Claude 的只读 Agent 工作区：它在独立 `CleanNestScanner.xpc` 中统计占用、区分工作痕迹、保护打开或近期写入的文件，并检查超大文件和两次完整基线间的增长。

本轮真机扫描没有读取会话正文、没有改动 Agent 目录，也没有执行归档、废纸篓移动、删除或进程结束。“0.6.3 回收计划”仍是预览，不是当前版本的操作入口。

## 失败关闭边界

- Agent 遍历最多处理每个 Agent 600,000 个目录项；达到上限、读取受限或取消都使相关分组预览归零。
- 打开文件表失败会使整个快照标记为不完整，所有回收预览归零，不会用这次数据覆盖上次可信基线。
- XPC 协议仅传输版本化 JSON `Data`；Agent 扫描使用独立客户端，不会中断用户发起的清理或磁盘扫描。
- 扫描器无归档、废纸篓、删除、进程控制或网络接口；服务不可用时显式失败，不回退到主 App 遍历。

## 尚未证明

- 本版本只验证 Codex 与 Claude 默认路径；对 Kimi、WorkBuddy、Hermes、OpenClaw、Trae、MiniMax Hub 等不作出清理安全承诺。
- 预览数字不是 APFS 实际可释放空间；0.6.3 实现处理链后仍需用前后 `df` 真实对比。
- 本地稳定签名不是 Developer ID；当前构建仍不是 Apple 公证的公开安装包。
- 当前仅有本场测试和构建证据；在对应提交推送并由 GitHub runner 执行前，不把 CI / CodeQL 冒充为已通过。
