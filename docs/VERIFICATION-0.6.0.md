## 结论

0.6.0 已把清理扫描、磁盘体积统计和磁盘证据构建迁入内嵌 `CleanNestScanner.xpc`。真机强制终止扫描服务后，主 App 仍存活、界面可操作，并保留上一次完整报告和完成元数据；随后可以自动启动新扫描服务完成下一次分析。不存在主进程扫描回退。

本轮只读扫描与故障注入没有选择、移动或删除任何用户文件。

## 设计边界

- XPC 协议只传输 JSON `Data`，不对连接开放任意安全编码类。
- 扫描服务的 exported object 只暴露协议版本、两类扫描、进度与取消；没有文件删除、App 卸载、进程结束或设置修改入口。
- 文件修改时间使用可精确往返的日期编码，不四舍五入到毫秒；执行前文件身份与完整 SHA-256 复核保持原有强度。
- 服务不可用、协议版本不匹配、中断或取消均显式失败，不回退到主 App 进程执行高成本扫描。

## 尚未证明

- 本报告不等于 48 小时常驻、反复睡眠/唤醒或数百万项极端目录的耐久测试。
- 本机稳定签名不是 Developer ID；当前构建仍不是 Apple 公证的公开安装包。
- Universal 2 CI 已纳入 XPC 的两架构编译和签名验证，但在对应提交推送并由 GitHub runner 执行前，本报告不把本地配置冒充云端 CI 通过。
