# 威胁模型

## 保护目标

- 用户文档、应用数据和系统文件不被越界或不可恢复地删除
- 进程操作不会因为 PID 重用、身份变化或模糊名称匹配而结束错误目标
- 文件正文、凭据和未脱敏主目录路径不会进入模型请求或公开日志
- macOS TCC、代码签名、Gatekeeper 和管理员授权不被绕过
- CI 与发布产物的来源、架构和信任等级不被夸大

## 主要攻击面与控制

| 攻击面 | 可能风险 | 当前控制 |
| --- | --- | --- |
| Mole 输出 | 路径注入、异常 JSON、权限错误后的重复扫描 | 独立进程、结构化解码；受保护目录权限失败后禁止原生回退 |
| 原生文件扫描 | 符号链接逃逸、超大目录耗尽资源 | 跳过符号链接、有界证据采样、可取消任务、扫描前 TCC 探测 |
| 手动清理决定 | 旧决定覆盖新风险、把受保护目录伪装成可清理项 | 只保存不可逆条目指纹；待清理复核仅允许确定性规则已确认的非高风险条目；新证据收紧边界时旧决定失效；决定无执行通道 |
| 文件处理 | 根目录/系统目录误删、废纸篓失败后永久删除 | 严格后代白名单、根与系统路径保护、只移到废纸篓、失败即停止 |
| 应用卸载 | 模糊匹配误删其他应用数据 | App 本体路径限制、Bundle ID 精确匹配、逐项预览 |
| 进程控制 | PID 重用、系统进程终止、未保存数据丢失 | 用户所有权与启动身份复核、保护名单、正常退出优先、强制结束再次确认 |
| 本机 AI | 提示注入、模型扩大范围或生成命令 | 仅回环、元数据 token、严格 schema、确定性规则覆盖模型、无执行通道 |
| 只读 MCP | 本机客户端读取隐私元数据、参数滥用 | stdio only、无网络监听、只读工具、有界查询、脱敏路径、严格参数 |
| 历史数据库 | 长期积累、其他本机进程读取 | 用户 Application Support、可选保留期限与清空；不声称抵御已取得用户权限的恶意软件 |
| GitHub 更新检查 | 恶意响应、伪造版本、跳转到第三方下载页 | 仅用户主动触发、HTTPS 官方 API、1 MiB 响应上限、语义版本解析、排除草稿/预发布、校验官方仓库发布页、不自动下载或安装 |
| GitHub Actions | 依赖替换、令牌滥用、伪装成可信发行版 | Action 固定提交、最小权限、SBOM/校验和/来源证明；CI 产物明确未公证且不自动发布 |

## 不在当前保证内

- 已经取得当前 macOS 用户权限或完全磁盘访问的恶意软件
- 被替换的 Mole、`mlx_lm.server`、本机模型或用户主动配置的 MCP 客户端
- 硬件故障诊断、恶意文件内容检测或完整反病毒能力
- Apple Developer ID 和公证链；在正式签名、公证、装订与 Gatekeeper 实测前，CI 产物不属于可信公开发行版

发现控制失效时按 [安全策略](../SECURITY.md) 私密报告，避免提交真实路径、凭据或未修复利用细节。
