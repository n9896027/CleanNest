# 威胁模型

## 保护目标

- 用户文档、应用数据和系统文件不被越界或不可恢复地删除
- 进程操作不会因为 PID 重用、身份变化或模糊名称匹配而结束错误目标
- 文件正文、凭据和未脱敏主目录路径不会进入模型请求或公开日志
- macOS TCC、代码签名、Gatekeeper 和管理员授权不被绕过
- CI 与发布产物的来源、架构和信任等级不被夸大

## 主要攻击面与控制

| 攻击面 | 可能风险 | 当前控制 |
| --- | --- | --- |
| 原生文件扫描 | 符号链接逃逸、超大目录或重复哈希耗尽资源、触发云端占位下载 | 跳过符号链接/包/隐藏项与未下载云端项目；目录深度、文件数和哈希候选数均有上限；任务可取消 |
| XPC 扫描边界 | 扫描器崩溃/卡死拖垮 UI、半成品覆盖可信结果、协议类型扩张 | 高成本遍历只在独立签名的内嵌 XPC 服务中运行；仅传输版本化 JSON `Data`；服务中断时主 App 保持存活并回滚报告与扫描元数据；不存在主进程扫描回退；连接关闭后服务退出 |
| Agent 工作区 | 把活跃会话误判为垃圾、恶意规则扩大根、把“同机运行”误报为模型依赖、路径替换/竞态、备份损坏、恢复覆盖 Agent 新数据、私有索引失配、超大事务耗尽空间 | 独立 XPC 元数据遍历、不读正文、不跟随符号链接；签名者/代码签名/schema/相对路径四层规则校验；模型关系只接受已建立 TCP；打开文件与近 15 分钟写入双重保护；每个 Agent 600,000 项/5,000 令牌上限；执行供应方硬编码为 Codex/Claude 且仅限静置缓存/临时/日志；两次复核精确身份；同卷硬链接备份源、ZIP CRC 校验、排他原子移动与反向回滚；恢复冲突失败关闭；会话/索引继续只读；变更层只链接 GUI |
| 开发工具原生清理 | CLI 版本漂移、过期预演、广域 prune 删除仍需数据、工具联网或暴露路径 | 每次 Git/Hugging Face 执行前重新运行官方 dry-run；Git 范围由用户选择且不遍历仓库；Docker/npm/pip 无等价预演时只读；固定可执行文件与参数、超时、有限输出；Hugging Face 强制离线/禁遥测；前后 APFS 实测与活动审计 |
| 下载、媒体与重复检测 | 把唯一个人文件误报为可清理、局部指纹/哈希碰撞或扫描后文件替换 | 个人文件永不自动勾选；下载与媒体规则只建立复核候选；重复先按大小和首尾指纹筛选，但只有完整 SHA-256 一致才成立，并明确保留副本；执行前复核两端文件身份和完整哈希 |
| 手动清理决定 | 旧决定覆盖新风险、把受保护目录伪装成可清理项 | 只保存不可逆条目指纹；待清理复核仅允许确定性规则已确认的非高风险条目；新证据收紧边界时旧决定失效；决定无执行通道 |
| 文件处理 | 根目录/系统目录误删、个人目录授权外溢、废纸篓失败后永久删除 | 缓存接口保持原严格后代白名单；个人文件只走带扫描身份的独立根边界；根与系统路径保护、只移到废纸篓、失败即停止 |
| 应用卸载 | 模糊匹配误删、扫描后目标替换、权限判断失真 | App 本体仅限标准 Applications 目录；执行前后复核设备号、文件号与 Bundle ID；同卷移动使用排他原子重命名避免覆盖；权限不足才交给 Finder 原生认证；App 本体未确认进入废纸篓时不处理相关文件 |
| 进程控制 | PID 重用、系统进程终止、未保存数据丢失 | 用户所有权与启动身份复核、保护名单、正常退出优先、强制结束再次确认 |
| 本机 AI | 提示注入、模型扩大范围或生成命令 | 仅回环、元数据 token、严格 schema、确定性规则覆盖模型、无执行通道 |
| 模型运行时发现/启停 | 暴露内网地址或参数、误认健康、PID 重用、结束错误进程、守护服务反复拉起、误停系统 LaunchDaemon | 仅本机进程/监听/平台 API 与标准 launchd 元数据；地址不持久化，命令行和 plist 参数只做内存分类且不展示；外部进程复核 PID/时间/用户/可执行文件后先 SIGTERM；守护停用另行复核标签、gui 作用域、当前用户所有权、标准目录及 plist 设备号/文件号，只对精确用户 LaunchAgent 执行 disable/bootout，系统和其他用户守护只读；强制结束需二次勾选 |
| 只读 MCP | 本机客户端读取隐私元数据、参数滥用 | stdio only、无网络监听、只读工具、有界查询、脱敏路径、严格参数 |
| 历史数据库 | 长期积累、其他本机进程读取 | 用户 Application Support、可选保留期限与清空；不声称抵御已取得用户权限的恶意软件 |
| GitHub 更新检查 | 恶意响应、伪造版本、跳转到第三方下载页 | 仅用户主动触发、HTTPS 官方 API、1 MiB 响应上限、语义版本解析、排除草稿/预发布、校验官方仓库发布页、不自动下载或安装 |
| GitHub Actions | 依赖替换、令牌滥用、伪装成可信发行版 | Action 固定提交、最小权限、SBOM/校验和/来源证明；CI 产物明确未公证且不自动发布 |

## 不在当前保证内

- 已经取得当前 macOS 用户权限或完全磁盘访问的恶意软件
- 被替换的 `mlx_lm.server`、本机模型或用户主动配置的 MCP 客户端
- 硬件故障诊断、恶意文件内容检测或完整反病毒能力
- 小云雀与任意自定义 Agent 数据根在没有可复现样本前只显示待验证；Pi Agent、Kimi、WorkBuddy、Hermes、OpenClaw、Trae 与 MiniMax Hub 虽可建立只读账本，但 0.6.4 不处理其任何文件
- 未经正式签名、公证、装订与 Gatekeeper 实测的 CI ad-hoc 产物不属于可信公开发行版；本机已建立 Developer ID 与公证构建链，不代表任意历史产物或第三方下载都可信

发现控制失效时按 [安全策略](../SECURITY.md) 私密报告，避免提交真实路径、凭据或未修复利用细节。
